# ChromaSol — páginas públicas

Sitio estático que sirve las URL que exige el App Store para **ChromaSol**
(`com.andreseloy.colorsapp`): política de privacidad y soporte, en español, alemán e inglés.

| Página | Alemán | Inglés | Español |
|---|---|---|---|
| Inicio | `index.html` | `index.en.html` | `index.es.html` |
| Privacidad | `privacy.html` | `privacy.en.html` | `privacy.es.html` |
| Soporte | `support.html` | `support.en.html` | `support.es.html` |

Las páginas se generan en el repo privado `colorsApp` (`docs/site/`) y se copian aquí; no se
editan a mano. GitHub Pages sirve la rama `main` desde la raíz.
